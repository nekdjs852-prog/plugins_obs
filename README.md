# 📅 Day Mood Calendar (Календарь настроений)

Красивый и простой плагин для **Obsidian**, который позволяет отслеживать ваше настроение по дням прямо в боковой панели. Оценивайте каждый день и визуализируйте свою эмоциональную динамику с помощью интуитивного календаря с цветовой маркировкой.

---

## ✨ Основные возможности

*   **📅 Интерактивный календарь**: Удобная сетка дней текущего и прошлых месяцев прямо в интерфейсе Obsidian.
*   **🎭 3 уровня настроения**: Оценивайте свои дни в один клик:
    *   🙂 **Хорошо** — отличный, продуктивный или просто приятный день.
    *   😐 **Нормально** — обычный день без ярких потрясений или радостей.
    *   ☹️ **Плохо** — сложный день, усталость или плохое самочувствие.
*   **🎨 Цветовая маркировка**: Дни окрашиваются в соответствующие цвета настроения, помогая с первого взгляда оценить общую картину месяца.
*   **💾 Автосохранение**: Данные о настроении сохраняются локально в файле плагина `data.json` и не отправляются в облако.

---

## 🚀 Как пользоваться

1.  **Открыть календарь**:
    *   Нажмите на иконку календаря в левой панели (Ribbon Icon).
    *   Или откройте палитру команд (`Ctrl+P` / `Cmd+P`) и введите `Day Mood Calendar: Open Calendar`.
2.  **Отметить настроение**:
    *   Нажмите на любой день в календаре.
    *   В появившемся окне выберите нужное настроение (Плохо, Нормально или Хорошо).
    *   Цвет дня обновится автоматически, а на ячейке появится соответствующий смайлик.

---

## 🛠️ Структура проекта

*   `main.js` — скомпилированный код плагина.
*   `styles.css` — стили для отображения календаря и модального окна выбора настроения.
*   `manifest.json` — метаданные плагина для Obsidian.
*   `data.json` — файл с сохраненной историей вашего настроения.
