# Interactive Board — плагин для Obsidian

Полноценная интерактивная доска прямо внутри Obsidian: фигуры, соединители, рисование от руки и лазерная указка — всё в одном месте. А с новой версии ещё и **система слоёв в стиле Figma**: каждый объект на доске можно поднимать, опускать, прятать и переименовывать.

Доски хранятся прямо в вашем хранилище как обычные `.board.json` файлы — лежат рядом с заметками, открываются двойным кликом, версионируются в git как любой текст.

---

## Что нового в этой версии

- 🗂️ **Слои как в Figma.** Появилась панель слоёв: список всех объектов сверху вниз. Перетаскиванием меняете порядок, глазом — прячете/показываете, двойным кликом — переименовываете. Любую фигуру можно поставить над нарисованными линиями или под ними.
- ✍️ **Починили текст.** Раньше при наборе текста пробел не печатался, Backspace удалял всю фигуру, а буквы переключали инструменты. Теперь во время редактирования клавиатура работает как положено, а пробелы больше не «съедаются».
- 🎚️ **Настройки текста под рукой.** Выделяете фигуру или текст — и в тулбаре сразу появляются размер, шрифт и цвет именно для неё. Больше не нужно сначала выбирать инструмент.
- 🔦 **Лазер всегда сверху.** Указка рендерится поверх всего и не зависит от слоёв — она временная и нужна только чтобы показывать.

## Что умеет

| Возможность | Описание |
|-------------|----------|
| **Фигуры** | Прямоугольник, эллипс, текстовый блок, группа/контейнер, изображение (drag-and-drop или вставка из буфера) |
| **Соединители** | Прямые, кривые (квадратичные), ортогональные; настраиваемые стрелки, цвет, пунктир; можно отцеплять концы |
| **Рисование от руки** | Карандаш, маркер (полупрозрачный), ластик; сглаженные кривые. Можно рисовать поверх фигур |
| **Слои** | Панель слоёв: порядок перетаскиванием, скрыть/показать, переименование. Единый z-порядок для всех объектов |
| **Лазерная указка** | Затухающий след со свечением; настраиваемая длительность и кривая затухания. Всегда поверх остального |
| **Бесконечный холст** | Панорамирование, масштабирование, сетка, привязка к сетке |
| **Полноэкранный режим** | Скрывает панели Obsidian; плавающий тулбар автоматически прячется |
| **Отмена / Повтор** | Полный стек истории для всех операций |
| **Автосохранение** | Автоматически пишет в `*.board.json` в вашем хранилище |
| **Экспорт** | PNG, SVG (с учётом порядка слоёв и скрытых объектов) или сырой JSON |
| **Темы** | Автоматически подхватывает тёмную и светлую тему Obsidian |

## Слои

Кнопка **«Слои»** в тулбаре открывает панель справа. В ней — все объекты доски сверху вниз (верхний в списке = верхний на холсте).

В панели можно:
- **перетащить** строку, чтобы изменить порядок;
- нажать **глаз**, чтобы временно скрыть или показать объект;
- **двойным кликом** по имени — переименовать;
- **кликнуть** по строке, чтобы выделить объект на холсте.

Тот же порядок можно менять и без панели — правым кликом по фигуре («На передний/задний план», «Выше/Ниже») или горячими клавишами (см. ниже).

Линии рисования и коннекторы — такие же полноценные объекты со своим местом в стопке, поэтому фигуру легко спрятать под рисунок или, наоборот, поднять над ним.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `V` | Выделение |
| `R` | Прямоугольник |
| `E` | Эллипс |
| `T` | Текст |
| `I` | Изображение |
| `C` | Соединитель |
| `P` | Карандаш |
| `M` | Маркер |
| `X` | Ластик |
| `L` | Лазерная указка |
| `]` / `[` | Поднять / опустить выделенное на один слой |
| `Shift+]` / `Shift+[` | На передний / задний план |
| `Space` + перетаскивание | Панорамирование холста |
| `Ctrl` + колёсико | Масштабирование |
| `Ctrl+Z` | Отмена |
| `Ctrl+Y` | Повтор |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить фигуры |
| `Delete` | Удалить выделенное |
| `F11` | Полноэкранный режим |
| Двойной клик по фигуре | Редактировать текст |

> Горячие клавиши не срабатывают, пока вы редактируете текст или переименовываете слой, — клавиатура в этот момент полностью ваша.

## Формат файла

Доски сохраняются как `*.board.json` в хранилище. Структура:

```json
{
  "version": 1,
  "nodes": [...],
  "connectors": [...],
  "strokes": [...],
  "viewport": { "x": 0, "y": 0, "zoom": 1 },
  "laserParams": { ... }
}
```

У каждого объекта (фигуры, штриха, коннектора) есть общие поля слоёв:

- `zIndex` — позиция в общем порядке (больше = выше);
- `name` — имя для панели слоёв;
- `hidden` — скрыт ли объект.

Старые доски без этих полей открываются нормально: им проставляются значения по умолчанию, а прежний внешний вид сохраняется (линии остаются поверх фигур, коннекторы — под ними).

### Пример штриха

```json
{
  "id": "stroke1",
  "type": "stroke",
  "tool": "pencil",
  "layer": "permanent",
  "points": [[100,120],[102,125],[110,130]],
  "color": "#ffcc00",
  "width": 3,
  "opacity": 1,
  "smoothing": 0.6,
  "zIndex": 5,
  "name": "Карандаш",
  "hidden": false
}
```

## Настройки плагина

Открываются через **Настройки → Interactive Board**:

- **Размер сетки** — размер ячейки в пикселях (10–80)
- **Привязка к сетке** — включить/выключить
- **Цвета по умолчанию** — заливка и обводка фигур, цвет соединителей
- **Интервал автосохранения** — в миллисекундах
- **Сохранять временные штрихи** — нужно ли сохранять аннотации на временном слое
- **Лазер** — цвет, толщина, длительность затухания, кривая (линейная/экспоненциальная), радиус свечения

## Сборка и установка

### Что нужно
- [Node.js](https://nodejs.org/) версии 18 и выше

### Команды

```bash
# Установка зависимостей
npm install

# Режим разработки (watch)
npm run dev

# Продакшн-сборка
npm run build
```

### Установка в Obsidian

1. Соберите плагин (`npm run build`)
2. Скопируйте три файла в папку плагинов вашего хранилища:
   ```
   <хранилище>/.obsidian/plugins/interactive-board/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
   (можно скопировать и всю папку проекта целиком — Obsidian возьмёт только эти три файла)
3. Перезапустите Obsidian или перезагрузите плагин
4. Включите **Interactive Board** в Настройки → Сторонние плагины

```
src/
├── main.ts              — точка входа: плагин, команды, настройки

├── NodeManager.ts       — CRUD для фигур (DOM-рендеринг)
├── ConnectorManager.ts  — CRUD для соединителей (пообъектные SVG)
├── DrawManager.ts       — рисование от руки: постоянные штрихи как SVG, превью на canvas

├── SelectionManager.ts  — выделение, резиновая рамка, буфер обмена, редактирование текста
├── LayersPanel.ts       — панель слоёв (список, drag-and-drop, глаз, переименование)

├── Toolbar.ts           — плавающий тулбар
├── ExportModal.ts       — модальное окно экспорта

manifest.json            — манифест плагина Obsidian
styles.css               — все стили (используют CSS-переменные Obsidian)
example.board.json       — пример файла доски
```

## Архитектура

```
┌─────────────────────────────────────────────────┐
│  InteractiveBoardPlugin (main.ts)               │
│  - регистрация View, команд, настроек           │
└───────────────┬─────────────────────────────────┘
                │
   ┌────────────▼────────────────────┐
   │  CanvasView                     │
   │  - вьюпорт (пан/зум)            │
   │  - роутинг событий              │
   │  - единый z-порядок слоёв       │
   │  - автосохранение, render loop  │
   └──┬────┬────┬────┬────┬────┬────┘
      │    │    │    │    │    │
      ▼    ▼    ▼    ▼    ▼    ▼
   Node  Conn  Draw  Laser Sel  Layers
   Mgr   Mgr   Mgr   Rnd   Mgr  Panel
              │
              ▼
          History Mgr
```

**Рендеринг.** Фигуры (DOM), линии (SVG) и коннекторы (SVG) живут в одном мировом слое как соседи и упорядочиваются единым `z-index` — поэтому любой объект можно поставить над или под любым другим. Сетка снизу, поверх всего — временный слой превью рисования и лазер.

**Слои (снизу вверх):**
1. Сетка (canvas)
2. Мировой слой: фигуры, линии и коннекторы вперемешку по `z-index`
3. Превью текущего штриха (canvas)
4. Лазерные штрихи (canvas) — всегда сверху
5. Тулбар и панель слоёв (плавающие)
