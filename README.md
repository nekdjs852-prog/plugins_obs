# Reading Time

Плагин для [Obsidian](https://obsidian.md), который показывает примерное **время чтения** активной заметки, рассчитанное по количеству слов.

## Что делает

- Считает количество слов в активной заметке и оценивает время чтения.
- Показывает результат **в начале заметки** (над содержимым) в режиме чтения/предпросмотра.
- Дублирует результат в **статус-баре** внизу окна — он виден и в режиме редактирования.
- Значение **обновляется автоматически** при переключении между заметками и при редактировании текста.

## Установка (вручную)

1. Создайте папку плагина в вашем хранилище:
   `<ваше_хранилище>/.obsidian/plugins/reading-time/`
2. Скопируйте в неё файлы:
   - `main.js`
   - `manifest.json`
   - `styles.css`
3. В Obsidian откройте **Настройки → Сторонние плагины (Community plugins)**, отключите безопасный режим и включите плагин **Reading Time**.

> `main.js` появляется после сборки (см. ниже). Файлы `main.ts`, `tsconfig.json`, `esbuild.config.mjs`, `package.json` нужны только для разработки — в папку плагина их копировать не обязательно.

## Сборка

Требуется установленный [Node.js](https://nodejs.org/).

```bash
npm install      # установить зависимости разработки
npm run build    # проверка типов + сборка main.js (production)
npm run dev      # сборка в режиме разработки с автопересборкой
```

Команда `npm run build`:
1. запускает `tsc -noEmit` для проверки типов в строгом режиме;
2. собирает `main.ts` в `main.js` через esbuild (модуль `obsidian` помечен как external).

## Настройки

В разделе настроек плагина доступны:

- **Скорость чтения** — слов в минуту, по умолчанию `200`, диапазон `50–600`.
- **Подпись** — текст перед значением, по умолчанию `Время чтения:`.
- **Показывать количество слов** — добавляет число слов рядом со временем.

## Принцип работы (для отчёта)

1. **Получение текста.** Плагин берёт активное представление Markdown
   (`getActiveViewOfType(MarkdownView)`) и читает текст заметки из редактора
   (`editor.getValue()`), а при его отсутствии — из данных представления.

2. **Подсчёт слов.** Текст обрезается по краям и разбивается регулярным
   выражением `\s+` (любые пробелы и переносы строк). Пустые элементы
   отбрасываются, остаётся число слов. Markdown-разметка специально не
   вычищается — для оценки времени достаточно базового подсчёта.

3. **Расчёт времени.** Время = `слова / скорость_чтения`, округление вверх
   (`Math.ceil`) до целых минут. Если получается меньше минуты, выводится
   `< 1 мин`.

4. **Отображение.** Строка формируется из подписи, времени и (опционально)
   количества слов с правильным склонением. Результат вставляется блоком
   `div.reading-time-block` перед содержимым в режиме чтения и одновременно
   выводится в статус-бар.

5. **Обновление.** Подписки на события рабочей области Obsidian:
   `active-leaf-change` (смена заметки), `editor-change` (правка текста, с
   задержкой через `debounce`), `layout-change` (смена режима). Это
   обеспечивает актуальность значения без ручного обновления.

6. **Оформление.** Стили используют CSS-переменные темы Obsidian
   (`var(--text-muted)`, `var(--font-ui-small)`), поэтому вид совпадает с
   текущей темой, а цвет приглушённый.
