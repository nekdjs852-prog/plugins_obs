# Timeline View — плагин для Obsidian

Плагин визуализирует ваши заметки по датам в двух режимах: **месячный календарь** (сетка дней) и **горизонтальный таймлайн** (прокручиваемая шкала). Даты берутся из frontmatter — никакой дополнительной разметки не нужно.

Написан на TypeScript + React, работает через Obsidian Plugin API.

## Что умеет

- **Два режима отображения** — переключение между видом «Календарь» (месячная сетка) и «Таймлайн» (горизонтальная шкала) прямо из тулбара.
- **Календарь** — привычная сетка дней по месяцам с подсветкой выходных, сегодняшнего дня и событиями внутри ячеек.
- **Горизонтальный таймлайн** — прокручиваемая ось с раскладкой событий по дорожкам и маркером «сегодня».
- **Чтение frontmatter** — подхватывает поля `date`, `end`, `title`, `tags`, `color`.
- **Точечные и диапазонные события** — если указана только `date`, событие отображается как карточка-точка; если добавлено `end` — как блок-диапазон.
- **Клик и тултипы** — нажатие на событие открывает заметку, при наведении — подсказка с деталями.
- **Автообновление** — таймлайн обновляется сам при создании, редактировании, переименовании и удалении заметок.
- **Фильтры и масштаб** — фильтрация по тегам и папкам, переключение масштаба: неделя / месяц / год.
- **Поддержка тем** — корректно выглядит в тёмной и светлой теме, использует CSS-переменные Obsidian.
- **Модальные окна** — добавление существующей заметки или создание новой прямо из интерфейса (правый клик).

## Формат frontmatter

```yaml
---
date: 2026-06-12      # дата начала (обязательно); также принимается `start`
end: 2026-06-20       # дата окончания (необязательно) — событие отрисуется как диапазон
title: Экзамен        # необязательно, по умолчанию берётся имя файла
tags: [учёба, экзамен] # необязательно
color: "#e25563"      # необязательно, любой CSS-цвет
---
```

## Сборка и установка

> Нужен [Node.js](https://nodejs.org) версии 18 или выше.

```bash
npm install
npm run build          # собирает main.js; для режима наблюдения — npm run dev
```

После сборки скопируйте `main.js`, `manifest.json` и `styles.css` в папку
`<ваше-хранилище>/.obsidian/plugins/timeline-view/` и включите плагин в
**Настройки → Сторонние плагины**.

## Структура проекта

```
src/
 ├── main.ts                          # точка входа: регистрация плагина и команд
 ├── views/
 │    └── TimelineView.ts             # ItemView с React-рутом и логикой автообновления
 ├── parser/
 │    └── eventParser.ts              # разбор frontmatter → TimelineEvent
 ├── models/
 │    └── TimelineEvent.ts            # типы данных
 ├── modals/
 │    ├── AddExistingNoteModal.ts     # модалка добавления существующей заметки
 │    └── CreateNoteModal.ts          # модалка создания новой заметки
 └── components/
      ├── timelineLayout.ts           # геометрия шкалы, дорожек и засечек
      ├── Timeline.tsx                # состояние, фильтрация, переключение режимов
      ├── CalendarView.tsx            # режим «Календарь» — месячная сетка
      ├── TimelineEventCard.tsx       # карточка одного события (точка или диапазон)
      └── Toolbar.tsx                 # панель управления: режим / масштаб / теги / папки
styles.css                            # стили плагина
```
