# Interactive Board — плагин для Obsidian

Плагин добавляет в Obsidian полноценную интерактивную доску: фигуры, соединители, рисование от руки и лазерная указка — всё в одном месте. Доски сохраняются прямо в хранилище как `.board.json` файлы, так что они всегда рядом с остальными заметками.

---

## Что умеет

| Возможность | Описание |
|-------------|----------|
| **Фигуры** | Прямоугольник, эллипс, текстовый блок, группа/контейнер, изображение (drag-and-drop) |
| **Соединители** | Прямые, кривые (квадратичные), ортогональные; настраиваемые стрелки, цвет, пунктир |
| **Рисование от руки** | Карандаш, маркер (полупрозрачный), ластик; сглаженные кривые. Можно рисовать прямо поверх фигур |
| **Лазерная указка** | Затухающий след с эффектом свечения; настраиваемая длительность и кривая затухания |
| **Бесконечный холст** | Панорамирование, масштабирование, сетка, привязка к сетке |
| **Полноэкранный режим** | Скрывает панели Obsidian; плавающий тулбар автоматически прячется |
| **Отмена / Повтор** | Полный стек истории для всех операций |
| **Автосохранение** | Автоматическое сохранение в `*.board.json` в вашем хранилище |
| **Темы** | Автоматически подхватывает тёмную и светлую тему Obsidian |

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `V` | Выделение |
| `R` | Прямоугольник |
| `E` | Эллипс |
| `T` | Текст |
| `C` | Соединитель |
| `P` | Карандаш |
| `M` | Маркер |
| `X` | Ластик |
| `L` | Лазерная указка |
| `Space` + перетаскивание | Панорамирование холста |
| `Ctrl` + колёсико | Масштабирование |
| `Ctrl+Z` | Отмена |
| `Ctrl+Y` | Повтор |
| `Ctrl+C` / `Ctrl+V` | Копировать / Вставить фигуры |
| `Delete` | Удалить выделенное |
| `F11` | Полноэкранный режим |
| Двойной клик по фигуре | Редактировать текст |

## Формат файла

Доски сохраняются как `*.board.json` в хранилище. Структура:

```json
{
  "version": 1,
  "nodes": [...],
  "connectors": [...],
  "strokes": [...],
  "viewport": { "x": 0, "y": 0, "zoom": 1 },
  "laserParams": { ... }
}
```

### Пример штриха

```json
{
  "id": "stroke1",
  "type": "stroke",
  "tool": "pencil",
  "layer": "permanent",
  "points": [[100,120],[102,125],[110,130]],
  "color": "#ffcc00",
  "width": 3,
  "opacity": 1,
  "smoothing": 0.6
}
```

## Настройки плагина

Открываются через **Настройки → Interactive Board**:

- **Размер сетки** — размер ячейки в пикселях (10–80)
- **Привязка к сетке** — включить/выключить
- **Цвета по умолчанию** — заливка и обводка фигур, цвет соединителей
- **Интервал автосохранения** — в миллисекундах
- **Сохранять временные штрихи** — нужно ли сохранять аннотации на временном слое
- **Лазер** — цвет, толщина, длительность затухания, кривая (линейная/экспоненциальная), радиус свечения

## Сборка и установка

### Что нужно
- [Node.js](https://nodejs.org/) версии 18 и выше

### Команды

```bash
# Установка зависимостей
npm install

# Режим разработки (watch)
npm run dev

# Продакшн-сборка
npm run build
```

### Установка в Obsidian

1. Соберите плагин (`npm run build`)
2. Скопируйте файлы в папку плагинов вашего хранилища:
   ```
   <хранилище>/.obsidian/plugins/interactive-board/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
3. Перезапустите Obsidian или перезагрузите плагины
4. Включите **Interactive Board** в Настройки → Сторонние плагины

## Структура проекта

```
src/
├── main.ts              — точка входа: плагин, команды, настройки
├── CanvasView.ts        — главный View, вьюпорт, роутинг событий, автосохранение
├── types.ts             — все TypeScript-интерфейсы и типы
├── NodeManager.ts       — CRUD для фигур (DOM-рендеринг)
├── ConnectorManager.ts  — CRUD для SVG-соединителей
├── DrawManager.ts       — рисование от руки: постоянный/временный/лазерный слои
├── LaserRenderer.ts     — рендеринг лазерной указки с анимацией затухания
├── SelectionManager.ts  — выделение, резиновая рамка, буфер обмена, редактирование текста
├── HistoryManager.ts    — стек отмены/повтора
├── FullscreenManager.ts — переключение полноэкранного режима
├── Storage.ts           — загрузка/сохранение *.board.json через Vault API
├── Toolbar.ts           — плавающий тулбар
├── ExportModal.ts       — модальное окно экспорта
└── SettingsTab.ts       — панель настроек Obsidian

manifest.json            — манифест плагина Obsidian
styles.css               — все стили (используют CSS-переменные Obsidian)
example.board.json       — пример файла доски
```

      │    │    │    │   │
      ▼    ▼    ▼    ▼   ▼

          History Mgr

**Слои рендеринга (снизу вверх):**
1. Сетка (canvas)
2. SVG-соединители
3. DOM-фигуры
4. Постоянные штрихи (canvas)
5. Временные штрихи (canvas)
6. Лазерные штрихи (canvas)
7. Тулбар (плавающий)
