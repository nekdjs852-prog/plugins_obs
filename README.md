# Weather Mood

Плагин для [Obsidian](https://obsidian.md), который показывает **анимированный баннер с реальной погодой** в шапке активной заметки. Данные берутся из [Open-Meteo](https://open-meteo.com) — бесплатного API без ключа.

## Возможности

- 🌦 Баннер в шапке заметки меняется в зависимости от текущей погоды.
- 🎞 CSS-анимации для каждого типа погоды:
  - **Дождь** — падающие капли;
  - **Солнце** — градиент с вращающимися лучами (ночью — луна);
  - **Снег** — кружащиеся снежинки;
  - **Облачно** — плывущие облака;
  - **Гроза** — вспышки молний поверх дождя;
  - **Туман** — приглушённые облака.
- 🌍 Местоположение по **названию города** (геокодинг Open-Meteo).
- ⏱ Настраиваемая частота обновления.
- 🎚 Переключатель анимаций (можно оставить статичный фон).

## Установка для разработки

```bash
npm install
npm run dev      # сборка в режиме watch
npm run build    # продакшн-сборка
```

Скопируйте `main.js`, `manifest.json` и `styles.css` в
`<хранилище>/.obsidian/plugins/weather-mood/` и включите плагин в настройках Obsidian.

## Настройки

| Параметр            | Описание                                       |
| ------------------- | ---------------------------------------------- |
| Город               | Название населённого пункта                     |
| Частота обновления  | Период опроса Open-Meteo в минутах (минимум 1)  |
| Анимации            | Вкл/выкл движущихся эффектов                     |

## Команды

- **Weather Mood: Обновить погоду** — принудительный запрос текущей погоды.

## Источники данных

- Погода: `https://api.open-meteo.com/v1/forecast`
- Геокодинг: `https://geocoding-api.open-meteo.com/v1/search`

Коды погоды (WMO weather codes) сопоставляются с категориями анимации внутри `main.ts`.
